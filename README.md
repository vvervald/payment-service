# Payment Service

Учебный проект на Go. 

Проект разбит на несколько Git-веток. Каждая следующая ветка добавляет новый уровень функциональности: от простых операций с балансом до конкурентной обработки транзакций и синхронизации общего состояния.

## Development Stages

Проект развивался поэтапно. Каждая ветка содержит отдельный этап реализации.

### Branch 1 — Basic User Operations

Базовая модель пользователя:

- User
- Deposit
- Withdraw
- проверка недостаточного баланса
- базовая обработка ошибок

### Branch 2 — Payment Service

Добавлен `PaymentService`:

- хранение пользователей;
- хранение транзакций;
- обработка переводов между пользователями.

### Branch 3 — Concurrent Transaction Processing

Добавлена конкурентная обработка транзакций:

- goroutines;
- channel с транзакциями;
- Worker Pool;
- sync.WaitGroup.

### Branch 4 — Synchronization

Добавлена защита общего состояния:

- sync.Mutex в User;
- синхронизация Deposit;
- синхронизация Withdraw;
- проверка проекта на race.


## Запуск программы

Переход в нужную ветку:

```bash
git checkout v1 # v1, v2, v3 или v4 
```

Запуск программы:

```bash
go run .
``` 

Для проверки на состояние гонки:

```bash
go run -race .
```
